## Installation
```shell
git clone <repo-url> .dotfiles

cd .dotfiles

# give executable permission
chmod +x setup.sh install.sh

# install packages
./install.sh

# setup dotfiles
./setup.sh

# give executable permissions to the necessary scripts
```bash
    cd scripts && find . -type f -exec chmod +x {} \;
```

```

# Start yabai
```bash
yabai --start-service
```
